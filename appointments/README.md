# אפליקציית זימון תורים

אתר סטטי (בלי שרת/build) לזימון תורים ללקוחות של ליאת, בהמשך לאותה שיטת אירוח (GitHub Pages) כמו מחשבון ציוני המבנים.

**האתר החי:** https://yoelnadel-lang.github.io/bridge-score-calculator-pages/appointments/
**אזור הניהול:** https://yoelnadel-lang.github.io/bridge-score-calculator-pages/appointments/admin.html

## איך זה עובד

האתר הוא סטטי לגמרי — אין מסד נתונים משותף בין המכשיר של הלקוח/ה לבין המכשיר של ליאת. לכן הזרימה היא:

1. הלקוח/ה בוחר/ת שירות, תאריך ושעה (לפי שעות הפעילות שהוגדרו) וממלא/ת פרטים.
2. בלחיצה על "שליחת בקשה" נפתחת הודעת וואטסאפ מוכנה למספר של ליאת עם כל הפרטים.
3. ליאת מאשרת את התור מול הלקוח/ה בוואטסאפ (ומוודאת שאין חפיפה לתור אחר).
4. ליאת מוסיפה את התור המאושר ל"אזור הניהול" משלה — שם יש לה יומן תורים מלא שנשמר בדפדפן שלה, כולל בדיקת התנגשויות אוטומטית בעת הוספה, ביטול/מחיקה, וגיבוי/שחזור.

**חשוב:** יומן הניהול נשמר בזיכרון הדפדפן (localStorage) של המכשיר שבו נכנסים ל-`admin.html` — יש להשתמש תמיד באותו דפדפן/מכשיר כדי לראות את כל התורים, ומומלץ לגבות מדי פעם עם כפתור "גיבוי (JSON)".

## התאמה אישית

כל ההגדרות נמצאות בקובץ [`config.js`](./config.js) עם הסברים בעברית — לא נדרש ידע תכנות, רק לערוך טקסט בין מרכאות:

- `businessName` — השם שמוצג בדף.
- `whatsappNumber` — מספר הוואטסאפ של ליאת (פורמט בינלאומי, למשל `972501234567`). כל עוד ריק, הלקוח יקבל טקסט להעתקה במקום קישור וואטסאפ.
- `adminPin` — קוד כניסה לאזור הניהול (לא הצפנה אמיתית, רק מחסום בסיסי).
- `services` — רשימת סוגי הפגישות ומשך כל אחת בדקות.
- `workHours` — שעות פעילות לכל יום בשבוע.

## אבטחה

קוד הגישה לניהול (`adminPin`) מוטמע בקובץ JS ציבורי, ולכן זה לא אמצעי אבטחה אמיתי — רק הגנה מפני כניסה מקרית. אין להזין באפליקציה מידע רגיש.
