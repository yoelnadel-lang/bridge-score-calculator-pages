# מחשבון ציוני מבנים — Condition PI

מחשבון אינטרנטי להערכת המצב המבני של גשרים, מובלים, גשרי שילוט, קירות תומכים/אקוסטיים ומנהרות,
לפי המתודולוגיה הרשמית של **נתיבי ישראל**:

- "הנחיות להערכת המצב המבני של גשרים, מנהרות ומבני דרך" — מהדורה 9-2019
- "פנקס לסוקר — טבלאות פגמים" — מהדורה 1-2016 (137 פגמים ב-17 משפחות, מוטמעים בטופס)
- "הנחיות לביצוע סקירת גשרים, מנהרות ומבני דרך" — מהדורה 6-2019
- "אוגדן חלוקה ומספור רכיבים" — מהדורה 1-2020

**האתר החי:** https://yoelnadel-lang.github.io/bridge-score-calculator-pages/

## מה המחשבון עושה

1. הזנת רכיבי המבנה לפי קטלוגי הרכיבים הרשמיים (חשיבות ויחידות אוטומטיות),
   בתיבות בחירה עם סינון תוך כדי הקלדה.
2. הזנת פגמים לפי הפנקס לסוקר — בחירת פגם מציגה את תיאורי דרגות החומרה לבחירה.
3. חישוב מלא של שרשרת הציון: ‏S&Ex → ECS → ECF → ECI → EIF → SCS → Condition PI.
4. ציון לכל מפתח (עד 30 מפתחים) + ציון מבנה משוקלל (לפי הנוהל — משוואה 6.2, ולצידו שקלול CPI ישיר).
5. פירוש הציונים לפי טבלה 15 + תקציר מנהלים אוטומטי + מחשבון מועד סקירה הבאה.
6. שמירה אוטומטית בדפדפן, ייצוא דוח PDF מלא (כולל נספח פירוט לכל מפתח), הדפסת דוח.

## כללי הנוהל הממומשים

- מבנה עם 1–2 מפתחים מחושב כיחידה אחת (משוואה 6.1); 3+ מפתחים — שקלול לפי מימד (משוואה 6.2).
- היקף A מותר רק עם חומרה 1; רכיב ביחידת "יח'" מדורג תמיד בהיקף B; ‏S=5 ⇒ ECS=5.0.
- רכיב "לא ניתן לסקירה" יוצא מהחישוב (ואינו נספר כתקין).
- רכיבי עזר נסקרים אך אינם נכללים בציון.

## אימות

מקבצי החישוב המקוריים, ובדיקת שקלול למבנה בן 15 מפתחים.
